# TrackerDeRutina

A laburar el cuerpo viejo 


## Qué hace

- Rutinas por repeticiones o por tiempo.
- Descansos entre ejercicios.
- Temporizador que se inicia manualmente.
- Ajuste de repeticiones durante el entrenamiento.
- Creador y editor de rutinas.
- Eliminación de ejercicios.
- Historial de entrenamientos.
- Importación y exportación en JSON.
- Funciona sin frameworks ni dependencias externas.
